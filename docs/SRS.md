# Software Requirements Specification (MVP)

## Purpose and scope
A browser-based portal to submit consumer complaints, validate essential fields, track status by reference, and let a reviewer approve or reject submissions. MVP has no file uploads or user authentication.

## Functional requirements
- FR-1: Display a complaint form with name, email, category, subject and description.
- FR-2: Reject missing fields, malformed email, and descriptions shorter than 10 characters.
- FR-3: Persist accepted complaints in the configured database and generate a reference.
- FR-4: Search a complaint by reference and display status, subject, category and reviewer note.
- FR-5: Reviewer lists submissions and decides APPROVED or REJECTED once, with an optional note.
- FR-6: Unknown reference produces a clear not-found message.

## Non-functional requirements
- Java 17+ and Spring Boot 3; Maven build.
- UI works in current Chromium browser; semantic labels and HTML validation.
- Container listens on port 8080; configurable port/database connection.
- Automated test report generated by Maven Surefire.
- Never commit secrets. Demo reviewer endpoint must not be internet-exposed.

## Use cases
1. Submit: Consumer → fill form → server validation → store → show reference.
2. Track: Consumer → enter reference → see status or not-found response.
3. Review: Reviewer → inspect pending complaints → approve/reject and add note.
4. Operate: Developer → commit → Jenkins build/test → image → deployment health check.

## Data model
Complaint(id PK, referenceId unique-by-convention, consumerName, email, category, subject, description, status, reviewerNote, createdAt). Status values: SUBMITTED, APPROVED, REJECTED.

## Web endpoints
| Method | Path | Purpose |
|---|---|---|
| GET | / | Submission form |
| POST | /complaints | Validate and save complaint |
| GET | /track?reference=CCP-... | Lookup status |
| GET | /review | Reviewer list |
| POST | /review/{id}/APPROVED | Approve pending complaint |
| POST | /review/{id}/REJECTED | Reject pending complaint |

## Architecture
Browser → Spring MVC/Thymeleaf → ComplaintController → Spring Data JPA → H2 database. Jenkins builds and tests Maven artifact, builds Docker image, optionally pushes to registry; Ansible configures target host and runs container.
